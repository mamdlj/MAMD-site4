# بات تلگرام متصل به Claude

این یه بات ساده‌ست که پیام‌های تلگرام رو به Claude می‌فرسته و جوابش رو برمی‌گردونه.

## مراحل راه‌اندازی

### ۱. ساخت بات تلگرام
1. تو تلگرام برید سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزنید و مراحل رو دنبال کنید (اسم و یوزرنیم بات رو ازتون می‌پرسه)
3. در آخر یه **توکن** بهتون می‌ده (چیزی شبیه `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`) — نگهش دارید.

### ۲. گرفتن کلید API از Anthropic
1. برید به [console.anthropic.com](https://console.anthropic.com)
2. یه حساب بسازید (یا وارد بشید)
3. از بخش **API Keys** یه کلید جدید بسازید و نگهش دارید.

### ۳. نصب و تنظیم پروژه
```bash
cd telegram-claude-bot
npm install
cp .env.example .env
```
بعد فایل `.env` رو باز کنید و دو مقدار رو جایگزین کنید:
```
TELEGRAM_BOT_TOKEN=توکن بات از باتفادر
ANTHROPIC_API_KEY=کلید API از Anthropic
```

### ۴. اجرای بات
```bash
npm start
```
اگه پیام «🤖 بات روشن شد و منتظر پیامه...» رو دیدید، یعنی کار می‌کنه. حالا برید تو تلگرام، بات خودتون رو پیدا کنید و پیام بدید.

## دستورات بات
- `/start` — شروع مکالمه جدید
- `/reset` — پاک کردن حافظه مکالمه فعلی

## دیپلوی روی سرور ابری رایگان (Railway) — پیشنهادی

چون تلگرام تو ایران فیلتره، بهترین راه اینه که بات رو روی یه سرور خارج از ایران اجرا کنید، نه سیستم خودتون. اینجوری هم نیازی به VPN/پروکسی نیست، هم بات همیشه (۲۴ ساعته) روشن می‌مونه.

### ۱. آپلود پروژه در گیت‌هاب
1. یه ریپازیتوری جدید تو گیت‌هاب بسازید (مثلاً `telegram-claude-bot`).
2. کل فایل‌های این پوشه (`bot.js`, `package.json`, `.gitignore`, `README.md`) رو توش آپلود کنید.
   ⚠️ فایل `.env` رو **آپلود نکنید** — چون شامل کلیدهای خصوصیه (به همین خاطر `.gitignore` گذاشتیم که خودکار نادیده گرفته بشه).

### ۲. ساخت حساب Railway
1. به [railway.app](https://railway.app) برید و با گیت‌هاب ثبت‌نام کنید.
2. روی **New Project** بزنید → **Deploy from GitHub repo** رو انتخاب کنید → همون ریپازیتوری که ساختید رو انتخاب کنید.

### ۳. تنظیم متغیرهای محیطی
1. تو پروژه‌ای که تو Railway ساخته شد، برید به تب **Variables**.
2. این دوتا رو اضافه کنید (مقدارهای واقعی خودتون رو بذارید):
```
TELEGRAM_BOT_TOKEN=توکن بات شما
ANTHROPIC_API_KEY=کلید API شما
```
(نیازی به `PROXY_URL` نیست، چون سرور Railway بیرون از ایرانه.)

### ۴. دیپلوی
Railway خودش بعد از اضافه‌کردن متغیرها، پروژه رو build و اجرا می‌کنه. تو تب **Deployments**، وقتی وضعیت سبز شد و لاگ‌ها «🤖 بات روشن شد...» رو نشون دادن، یعنی بات آنلاینه.

حالا تو تلگرام برید سراغ باتتون و پیام بدید — چون سرور بیرون از ایرانه، دیگه به مشکل فیلترینگ نمی‌خورید.

## نکات مهم
- تاریخچه‌ی مکالمه فقط تو حافظه (RAM) نگه داشته می‌شه — با ری‌استارت شدن برنامه پاک می‌شه. اگه بخواید دائمی باشه، باید به یه دیتابیس (مثل Supabase که قبلاً باهاش کار کردیم) وصلش کنیم.
- متن `SYSTEM_PROMPT` داخل `bot.js` رو می‌تونید عوض کنید تا شخصیت و لحن بات مطابق میلتون بشه.
- اگه بعداً خواستید روی سیستم خودتون هم تست کنید (بدون Railway)، همون مراحل قبلی (نصب، `.env`، `npm start`) رو دنبال کنید — ولی چون تو ایران فیلتره، باید `PROXY_URL` رو با یه پروکسی HTTP/SOCKS واقعی (نه لینک `t.me/proxy`) پر کنید.
